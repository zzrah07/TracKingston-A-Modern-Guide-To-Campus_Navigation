🚌 TracKingston
A Modern Guide to Campus Navigation

TracKingston is a real-time, role-based school bus tracking 
web app built with React and Firebase. It provides live GPS 
tracking, geofencing alerts, and dedicated dashboards for 
Students, Teachers, Drivers, and Administrators — eliminating 
bus wait times and enhancing student safety.

✨ Features
- 📍 Live bus tracking with real-time GPS
- 👥 Four role-based dashboards
- 🎫 Digital bus pass & fee management
- 📍 Geofencing alerts at each stop
- 🚨 Emergency SOS for drivers
- 🔔 Real-time notifications
- 📊 Admin analytics & defaulter reports

🛠️ Tech Stack
- **Frontend:** React.js
- **Auth:** Firebase Authentication
- **Database:** Firebase Firestore
- **Live GPS:** Firebase Realtime Database
- **Hosting:** Vercel
- **Language:** JavaScript (JSX)
